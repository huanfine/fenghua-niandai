# 《浮生万象：当代人生风云录》抖音项目快速上手指南

本目录支持两种直接运行模式，可根据您的发布诉求随时自由切换：

---

## 模式一：纯原生小游戏模式 (Mini Game Canvas 引擎 - 当前默认)
* **适用场景**：上架“抖音小游戏”类目、支持全屏互动与触控振动。
* **技术实现**：由 `game.js` 驱动原生 Canvas 2D 渲染，自带胶囊避让、安全区计算与触控微震反馈。
* **工程配置**：`project.config.json` 中 `"compileType": "game"`。
* **运行步骤**：
  1. 打开抖音（字节跳动）开发者工具，导入本目录；
  2. 模式选择 **小游戏**；
  3. 导入后直接点击【编译】，模拟器即可直接运行！

---

## 模式二：小程序 Web-View 容器模式 (100% 还原网页版原汁原味华丽界面)
* **适用场景**：希望完整保留原版 H5 中极致绚丽的 TailwindCSS 动效、立绘头像、命运大转盘、数十万字剧情与全部音效。
* **技术实现**：基于抖音小程序官方 `<web-view>` 组件，直接内嵌渲染原版网页。
* **工程配置**：
  1. 将 `project.config.json` 中的 `"compileType"` 改为 `"miniprogram"`；
  2. 在 `pages/index/index.js` 中将 `h5Url` 填入您的 H5 地址；
  3. 点击【编译】，即可在抖音中 1:1 完美呈现原版精美大作！
